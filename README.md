# LexFlow — Online Legal Case Management System

A responsive front-end project built with HTML, CSS and vanilla JavaScript.

## Features
- Dashboard with case, hearing and task summaries
- Case records with client, case type, stage, status and next hearing
- Client directory
- Hearing schedule
- Task list with completion checkboxes, due dates and priority
- Document register (stores document details, not file contents)
- Search and status filters
- Add and delete records
- Browser `localStorage` persistence

## Run the project
1. Extract `legal-case-management-system.zip`.
2. Open `index.html` in a modern browser.
3. Add or edit sample records from the interface.

No build tools or installation are required.

## Important note
This is a college-project front-end prototype. Data is saved only in the current browser using localStorage. It does not include a backend, user authentication, encrypted storage, cloud file uploads, or real court integrations. Do not enter confidential client information.
